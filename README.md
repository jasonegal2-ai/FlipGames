# FlipGames

Moderne PC-Gaming-Webseite mit Suche, Kategorien und Spielkarten.

## Live
Die Seite kann über GitHub Pages veröffentlicht werden.

## Hinweis
Die Demo verwendet externe Unsplash-Bilder. Für eine echte öffentliche Spieleplattform sollten nur Bilder und Inhalte verwendet werden, für die die nötigen Rechte vorliegen.
